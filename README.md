# 📝 Task Flow

> A powerful and clean **Todo List API** built with **Django REST Framework**.

---

## 🚀 Overview

**Task Flow** is a scalable and extensible RESTful API for managing todos and tasks.  
It is built with **Django** and **Django REST Framework (DRF)** — a solid foundation for any backend developer learning modern web API design.

---

## 🧠 Features

✅ User registration and authentication with JWT  
✅ Create, update, delete and retrieve tasks  
✅ Organize tasks with categories/tags  
✅ Filter, search and order tasks  
✅ Pagination support  
✅ API documentation with Swagger and Redoc  
✅ Modular structure — ready for future growth  
✅ Clean and readable code structure

---

## 🧰 Built With

- 🐍 Python 3.x  
- 🌐 Django  
- 📦 Django REST Framework  
- 🔐 Simple JWT  
- 📄 drf-yasg (Swagger / Redoc)
